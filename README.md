# Booba Life

Site vitrine non officiel dédié à la discographie de Booba.

## Déploiement

Ce dépôt est prêt pour GitHub Pages. La branche `main` sert les fichiers du site à la racine.

## Contenu

- Présentation sombre et dorée
- Sélection d'albums
- Mise en page responsive
- Aucun fichier audio hébergé
